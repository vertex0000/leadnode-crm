# LeadNode CRM

Apna free CRM: leads, node-based pipeline, lead journey, team, reports.
Data Google Sheet mein rehta hai (Google Apps Script backend).

**Live:** https://vertex0000.github.io/leadnode-crm/

## Kaise use karein
1. Link kholo. Pehli baar demo data dikhega.
2. Settings (neeche-left ⚙️) → **Connection** → Web App URL + API key daalo → Save & Connect.
3. Har naye device/browser pe ek baar ye karna hoga. Branding (logo, naam, photo) Sheet se apne aap aa jaati hai.

> Is repo mein koi password ya API key nahi hai. Key sirf tumhare browser mein save hoti hai.
